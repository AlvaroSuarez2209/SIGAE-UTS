# Logo institucional — pendiente

Esta carpeta está preparada para recibir el logo real de UTS. Mientras tanto, la
aplicación usa un placeholder de texto ("SIGAE-UTS" en Source Serif 4) tanto en
el login como en el sidebar.

Cuando se disponga del logo, colocar aquí:

| Archivo | Uso | Formato / dimensiones esperadas |
|---|---|---|
| `logo-full.svg` | Login (protagonista) | SVG preferido; si es PNG, transparente, ≥800×240 (lockup horizontal) o ≥512×512 (isotipo) |
| `logo-mark.svg` | Sidebar / navbar (uso pequeño) | SVG preferido; si es PNG, transparente, ≥320×80 (lockup) o ≥128×128 (isotipo) |

Y en `public/images/favicon-source.png`: PNG cuadrado transparente ≥512×512, a
partir del cual se generan los tamaños estándar de favicon (reemplazando el
`public/favicon.svg` provisional).

Al recibir el archivo real, verificar que el formato y las dimensiones
coincidan con lo esperado antes de integrarlo; si no coinciden, ajustar aquí
mismo la tabla y avisar antes de continuar.
